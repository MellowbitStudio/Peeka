# TestFlight 0.1.8

Peeka **0.1.8** has passed TestFlight review, as confirmed by the maintainer on **2026-10-29**. This is the confirmation date, not a claimed approval or release date. The build number and version-specific changes have not been confirmed in this reference.

- [Official TestFlight invitation](https://testflight.apple.com/join/5jM8yxDB)
- [Beta release notes and testing focus](https://mellowbit.studio/peeka/beta-release-notes/)
- [Stable release notes](https://mellowbit.studio/peeka/release-notes/)

For the stable release, see [Mac App Store 0.1.9](features-and-plans.md#app-store-019). The [0.1.6 Beta notes](testflight-0.1.6.md) cover the earlier Beta. Check the build currently offered by TestFlight before advising users to install it.

Check the version and build shown in TestFlight or the installed app when troubleshooting. Approval does not establish tester-group assignment, available places, or installation on a particular Mac. Feedback should include macOS, app version/build, file type, Pro and switch state, and reproduction steps.
